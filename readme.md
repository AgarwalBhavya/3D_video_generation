# Image/Text to 3D Model Generator

This prototype converts a single object image or a short text prompt into a basic 3D model (.stl format) and visualizes it.

## 🔧 Requirements
- Python 3.8+
- Virtualenv (recommended)

## 📦 Setup

```bash
git clone <repo>
cd 3d_generator
python -m venv venv
source venv/bin/activate  # on Windows: venv\Scripts\activate
pip install -r requirements.txt
